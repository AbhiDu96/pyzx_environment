# Pyzx Environmnet

This is the repository containing the RL environment used for the paper "Optimizing Quantum Circuits via ZX Diagrams using Reinforcement Learning and Graph Neural Networks" (code: https://github.com/MattAlexMiracle/ZXDiagramSimplification).
This is a general environment which publishes a state (in the form of a ZX graph or features) and accepts actions that correspond to pyzx graph-rewriting actions.
